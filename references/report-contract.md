# AD CS report contract

The standard report contains:

1. Executive summary with coverage and the issuance-versus-use caveat.
2. Plain-language remediation guide containing only ESC types with findings.
3. Technical analysis with data quality, coverage, evidence, confidence, and
   limitations.

The attack-path HTML and graph use only scrubbed tokens. The same graph model is
used for SVG, PNG, HTML, JSON, and Cypher. Visible graph/report text uses
`attack-path`, not vendor-specific product branding.

Audience modes may change wording and depth, but never change findings, evidence,
severity, or the missing-data policy.
