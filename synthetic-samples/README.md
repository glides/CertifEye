# CertifEye synthetic presentation scenarios

These three packages are fictional, deterministic, token-only datasets designed
to stress CertifEye without using or reproducing customer values.

| Scenario | Certificate rows | Evidence window | Intended outcome |
|---|---:|---|---|
| `all-esc-enterprise` | 16,800 | 2023-07-01 through 2026-06-30 | At least one finding in every supported ESC1–ESC11 area |
| `hardened-baseline` | 15,500 | 2023-07-01 through 2026-06-30 | Fully evaluated clean baseline with denied/parse-error negative controls |
| `mixed-enterprise` | 17,250 | 2023-07-01 through 2026-06-30 | Open, clean, mitigated, revoked, benign, and unreadable evidence |

Each `Scrubbed` folder contains the seven normal CertifEye input roles and a safe
source manifest. There is no token map because no original identity exists.
Tokens are intentionally different and non-overlapping between scenarios.

Each scenario also includes an `output` folder generated by the canonical
offline pipeline. It contains the findings CSV, PDF, self-contained HTML,
SVG graph, JSON/Cypher graph exports, and safe artifact manifest. These
committed outputs make the examples immediately reviewable and serve as golden
presentation artifacts. Regenerate them whenever analyzer or renderer behavior
is intentionally changed.

Generate all reports from the repository root:

```powershell
.\CertifEye\tools\Invoke-CertifEyeSyntheticDemo.ps1 `
  -Scenario All `
  -Destination C:\Temp\CertifEye-Demo
```

Use `-Replace` only when you intentionally want to overwrite that demo output.
Use `-IncludeQa` to request the optional montage step.

`scenario_expectations.json` is the versioned regression contract. Rebuild the
CSV packages deterministically with:

```powershell
python .\CertifEye\tools\New-CertifEyeSyntheticScenarios.py
```

Do not place customer data, raw exports, salts, token maps, or private manifests
in this directory.
